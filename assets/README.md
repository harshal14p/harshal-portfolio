# Project images/videos go here

Drop JPG / PNG / WEBP / MP4 files in this folder, then reference the file
name in `js/config.js` (inside the `PROJECTS` array, `image` and/or `video`
fields). Nothing elsewhere in the code needs to change — the "Selected
Work" section is rendered entirely from that array.

Example:
1. Add `assets/projects/my-shoot.jpg`
2. In `js/config.js`, set `image: "assets/projects/my-shoot.jpg"` on the matching project entry.
